# Musique de fond

Place ici un fichier nommé exactement `music.mp3` — c'est la piste qui sera automatiquement mixée en fond de chaque highlight généré.

Je ne peux pas te fournir directement un fichier audio (question de droits — même les pistes "libres de droit" restent des œuvres protégées avec une licence précise que je ne peux pas vérifier ni redistribuer à ta place). Télécharge-en une toi-même sur l'une de ces plateformes, en vérifiant bien la licence "usage commercial autorisé" si tu comptes utiliser ça au-delà de tests perso :

- **Pixabay Music** — https://pixabay.com/music/ (gratuit, pas d'attribution requise)
- **YouTube Audio Library** — https://studio.youtube.com/ → Audio Library (gratuit, filtre par usage)
- **Uppbeat** — https://uppbeat.io (freemium, licence claire par morceau)

## Recommandations
- Choisis un morceau **énergique/sport**, entre 30 sec et 3 min (il boucle automatiquement si trop court)
- Format **.mp3** obligatoire, nommé exactement `music.mp3`
- Dépose le fichier directement dans ce dossier (`backend/assets/music.mp3`) puis commit/push sur GitHub

Si ce fichier est absent, le site fonctionne quand même normalement — simplement sans musique de fond (le son original des vidéos reste tel quel).
